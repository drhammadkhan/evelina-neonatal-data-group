Neonatal data tools

Free, browser-based reference tools for neonatal clinicians. None of them send what you enter anywhere.

  • 01 · Screening

    ROP screening window calculator

    Find the first retinopathy of prematurity screening window from gestational age, birthweight and date of birth, following the RCPCH 2024 UK guideline.

    Open tool →Source on GitHub
  • 02 · Vaccination

    BCG tool

    Check whether a country’s estimated TB incidence is 40 per 100,000 or above, the UK Green Book threshold for BCG vaccination. Based on WHO estimates.

    Open tool →Source on GitHub
  • 03 · Imaging

    Ventricular index chart

    Plot right and left ventricular index against corrected gestational age on the Levene (1981) reference chart. Patient data stays on your device.

    Open tool →Source on GitHub
  • 04 · Neonatal jaundice

    Jaundice treatment thresholds

    Plot a baby’s serum bilirubin against the NICE CG98 phototherapy and exchange transfusion lines for their gestational age.

    Open tool →Source on GitHub
These tools support, and do not replace, clinical judgement and current guidance. They are reference aids, not certified medical devices. Use at your own discretion.
